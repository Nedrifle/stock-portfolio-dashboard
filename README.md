# 株式ポートフォリオ / Stockfolio

GitHub Pagesで動く日本株の管理アプリ。依存パッケージ不要のHTML/CSS/JavaScriptと、Python標準ライブラリのYahoo株価取得スクリプトで構成しています。

## 機能

- 複数ポートフォリオの作成、銘柄・現在株数・取得単価の登録／編集／削除
- 全体の時価評価額の日次推移、期間内の最高額・日付
- 直近共通営業日の損益内訳をウォーターフォールで表示（損失も表示）
- 銘柄別の取得価額、終値、時価評価額、含み損益、損益率、検索・並び替え
- 保有情報はlocalStorageに保存。CSV・JSONバックアップ／復元
- スマホ対応。サンプル4銘柄は保有情報として保存されません
- Yahoo取得の定期実行と、任意コードの手動取得

## GitHub Pagesへの公開

1. このディレクトリを専用リポジトリのmainブランチに配置します。個人の保有情報をリポジトリに入れないでください。
2. Settings → Pages → Build and deployment → Sourceを **GitHub Actions** にします。
3. リポジトリのGitHub Actionsを有効にします。必要な権限はこのアプリのワークフロー内で指定済みです。リポジトリ全体の既定権限を広げる必要はありません。
4. Actions →「株価取得とGitHub Pages公開」→ Run workflowを実行します。
5. PagesのURLを開きます。mainへのpush時、毎週月〜金18:17（日本時間）にも取得・公開します。GitHubの混雑や休日により更新時刻は前後します。

## 株価を取得する

通常の「株価を取得」はサイトに公開済みの株価キャッシュを再読込します。Yahooからその場で取得するには「株価取得の設定」を開きます。

- GitHub Pages上ではリポジトリをURLから自動入力します。
- Fine-grained personal access tokenは **対象リポジトリのみ / Actions: Read and write** に限定します。画面へ入力したトークンはメモリのみで使い、localStorageやバックアップには含めません。
- サイトの「Yahooから取得 → サイトに反映」で、保有銘柄の証券コードだけをワークフローへ渡します。完了後に最新データを再読込します。実行中に画面を閉じた場合は、後で「株価を取得」を押してください。
- トークンを使わない場合は「GitHubで実行画面を開く」でRun workflowを押し、symbolsに `7203.T,6758.T` のように入力できます。
- 追加コードはmarket-symbols.jsonに保存され、以後の定期取得対象になります。公開されるのは証券コードと株価だけです。
- アプリへの登録だけでは、未収録銘柄の株価は取得されません。取得設定から一度取得してください。

## 計算・分割

### CSVのデータ形式

見出しは `portfolio,symbol,name,quantity,cost` の5列です。1行が1銘柄で、同じportfolio名の行をまとめて読み込みます。quantityは現在の株数、costは分割調整後の1株当たり取得単価（円）です。小数を保持します。nameは空欄にできます。UTF-8（BOM付き推奨）に対応します。「データ管理」からCSVを書き出し／読込できます。読込時は現在の全ポートフォリオを置き換えるため確認画面を表示します。空のポートフォリオも保存する場合はJSONを使ってください。

`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?range=5y&interval=1d&events=splits` を利用します。これは米国Yahoo Financeの公開チャート用エンドポイントで、公式に提供を保証された開発者APIではありません。サービス変更や取得制限で失敗する場合があります。失敗した銘柄は前回データを保持し、画面に明示します。

**分割調整済みcloseを使い、配当調整後のadjcloseは使いません。** 現在の分割後株数と、対応する1株当たり取得単価を入力してください。将来分割が起きてもユーザーの株数・取得単価は自動変更しません。証券会社の保有残高に合わせて更新してください。

- 時価評価額 = 現在の保有株数 × 分割調整済み終値
- 取得価額 = 現在の保有株数 × 入力した取得単価
- 含み損益 = 時価評価額 − 取得価額
- 履歴は現在の株数を全期間持ち続けた仮定で再計算します。売買履歴・入出金・配当・税金・手数料は含みません。
- 全銘柄の終値がある共通営業日だけを合算。未収録銘柄を含む場合は部分的な合計を出しません。
- 取得日に日本時間17時を過ぎていなければ当日分を除外し、場中の価格を終値として扱いません。
- 対象は円建て東証株・ETF（`.T`）。他市場、外貨、非上場株は非対応です。

## ローカル実行

```sh
python3 -m http.server 8080 --directory site
# http://localhost:8080
```

```sh
node --test tests/*.test.js
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/update_prices.py --symbols '7203.T,6758.T'
```

`site/data/quotes.json` には公開市場データのみを配置します。個人情報・株数・取得単価・トークン・バックアップをコミットしないでください。公開サイトにはログイン機能はなく、端末内の保有データは別端末と自動同期されません。
