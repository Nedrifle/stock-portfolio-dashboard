株価取得の設定

Yahooの直近株価と確定終値をGitHub Actionsで取得し、このサイトに反映します。保有株数・取得単価は送信しません。

公開中のGitHub Pages URLからリポジトリを自動設定します。別の公開先では手入力してください。

今すぐYahooから取得する

GitHub Fine-grained tokenが必要です。対象リポジトリだけを選び、Actionsの読み書きを許可してください。トークンはメモリ内だけで使用し、ページを閉じると破棄します。

取得対象の公開証券コードはGitHub上に保存されます。株数・取得単価・ポートフォリオ名は保存されません。取引日は場中15分おきに直近株価、18:17頃に終値履歴を更新します。実行・公開が遅れる場合があります。

使い方と計算方法

  1. ポートフォリオを作成し、銘柄・株数・取得単価を登録します。
  2. 「最新データを読み込む」で公開済みの最新データを読み込みます。画面表示中も1分おきに読み直します。未取得銘柄は設定画面からYahoo取得を実行してください。
  3. 株式分割後の現在株数・取得単価を入力します。株数を自動で書き換えることはありません。
  4. バックアップを書き出せば、別端末にも引き継げます。

集計のルール

時価評価額＝現在株数×直近取得株価。含み損益＝時価評価額−取得価額。履歴グラフは現在株数をずっと保有した場合の再計算で、実際の売買履歴ではありません。

Yahooの分割調整済み終値（close）を使用し、配当調整後のadjcloseは使いません。配当・現金・手数料・税金を含みません。終値履歴は共通営業日だけを集計します。時価評価額と銘柄別損益は直近取得株価を使用し、一部未取得の場合は終値を含む参考評価と明示します。

Yahooの公開チャートエンドポイントを使っています。公式に提供を保証されたAPIではないため、取得に失敗する場合があります。その際は前回のデータを保持し、画面に状態を表示します。

情報はブラウザーのlocalStorageに保存されます。サイトデータを削除すると消えるため、適宜バックアップしてください。株価は公開データですが、あなたの保有情報は端末内だけに残ります。
